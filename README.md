# Паровой гараж

Android-приложение для учёта замены расходников автомобиля в стиле стимпанк: латунь, медь, тёмное дерево,
стрелочные манометры и рычаги. Полное техническое задание — в [SPEC.md](SPEC.md).

Приложение собирается по этапам (раздел «Этапы и критерии приёмки» в SPEC.md). Что уже готово —
в [CHANGELOG.md](CHANGELOG.md), принятые по ходу решения — в [DECISIONS.md](DECISIONS.md).

## Как установить на телефон

1. Откройте на телефоне страницу репозитория → справа **Releases** (или по ссылке
   `github.com/torintheone/avtobices/releases`) → последний релиз.
2. В разделе **Assets** нажмите на файл `steamgarage-<версия>.apk` — он скачается.
3. Откройте скачанный файл. Телефон спросит, можно ли устанавливать приложения из этого источника
   (браузера или «Файлов») — разрешите и нажмите «Установить».
4. Новые версии ставятся так же, поверх старой: данные сохраняются, если версии подписаны
   одним и тем же ключом (см. ниже).

## Ключ подписи (делается один раз)

Ключ подписи нужен, чтобы каждая новая версия ставилась поверх предыдущей без потери данных.
Файл ключа и пароль выдаёт Claude Code; файл ключа в репозиторий не кладётся.

1. Сохраните файл ключа `steamgarage-release.p12` и пароль в надёжном месте — например, в облачном диске.
   Если ключ потеряется, следующую версию придётся ставить начисто, с удалением данных.
2. На GitHub откройте репозиторий → **Settings** → **Secrets and variables** → **Actions** →
   **New repository secret** и добавьте четыре секрета (имя — в поле *Name*, значение — в поле *Secret*):

   | Name | Secret |
   | --- | --- |
   | `KEYSTORE_BASE64` | всё содержимое файла `KEYSTORE_BASE64.txt` (одна длинная строка) |
   | `KEYSTORE_PASSWORD` | пароль ключа |
   | `KEY_ALIAS` | `steamgarage` |
   | `KEY_PASSWORD` | тот же пароль ключа |

Пока секретов нет, APK подписывается временным ключом, и в журнале сборки видно предупреждение.

## Если уведомления о сроках не приходят

1. Откройте в приложении **Настройки** → раздел «Уведомления». Если там написано, что уведомления запрещены,
   нажмите «Разрешить уведомления» и включите их в открывшихся настройках телефона.
2. На телефонах Xiaomi, Redmi, POCO, Huawei, Honor, OPPO, Vivo, Realme, OnePlus и похожих фоновые проверки
   часто останавливаются. Нажмите в настройках приложения «Автозапуск и батарея»: включите «Автозапуск»,
   а в разделе «Батарея» (или «Контроль активности») выберите «Нет ограничений».
3. Для проверки нажмите «Проверить сроки сейчас». Если у какого-то расходника срок подошёл
   и о нём ещё не сообщали, уведомление придёт через несколько секунд. О расходнике в статусе «Скоро»
   приложение напоминает один раз, о статусе «Пора менять» — раз в неделю, пока не запишете замену.

## Firebase — для синхронизации между телефонами

Без Firebase приложение работает полностью, только раздел «Общий гараж» в настройках напишет,
что синхронизация не настроена. Настройка делается один раз, минут за 15, можно с телефона.
**Порядок важен:** база данных создаётся до скачивания конфига.

1. Откройте [console.firebase.google.com](https://console.firebase.google.com) → «Создать проект»
   (имя любое, например `steamgarage`). Google Analytics можно выключить.
2. **Build → Authentication** → «Начать» → вкладка **Sign-in method** → «Анонимный» → включить → «Сохранить».
3. **Build → Realtime Database** → «Создать базу данных» → регион **Europe** → «Начать в заблокированном режиме».
   Откройте вкладку **«Правила»**, сотрите всё и вставьте текст ниже → «Опубликовать».

   ```json
   {
     "rules": {
       "garages": {
         "$gid": {
           ".read": "auth != null && data.child('members').child(auth.uid).exists()",
           "members": {
             "$uid": {
               ".write": "auth != null && auth.uid === $uid"
             }
           },
           "$other": {
             ".write": "auth != null && root.child('garages').child($gid).child('members').child(auth.uid).exists()"
           }
         }
       }
     }
   }
   ```

   Что они значат: читать гараж могут только его участники, записать себя в участники может тот,
   кто знает код, а менять машины и записи — только участники.
4. Шестерёнка «Настройки проекта» → «Ваши приложения» → значок Android → имя пакета `app.steamgarage`
   (SHA-1 не нужен) → «Зарегистрировать» → **«Скачать google-services.json»**. Если файл скачан
   до создания базы, скачайте его заново: в нём должен быть адрес базы.
5. **Этот репозиторий публичный**, поэтому сам файл в него не загружайте. На GitHub откройте
   **Settings → Secrets and variables → Actions → New repository secret**: Name — `GOOGLE_SERVICES_JSON`,
   Secret — всё содержимое файла (откройте его в любом текстовом редакторе и скопируйте целиком).
6. Следующая сборка будет уже с синхронизацией — в её журнале появится строка «Firebase настроен».

**Как пользоваться общим гаражом:**

1. На первом телефоне: **Настройки → «Создать гараж» → «Поделиться кодом»**.
2. На остальных телефонах: установить тот же APK, при первом запуске нажать «Вступить в гараж по коду»
   (или позже: Настройки → «Вступить в гараж») и вставить код. Можно просто навести обычную камеру
   телефона на QR-код в настройках первого телефона — приложение откроется с этим кодом.
3. Откройте машину и включите **«Общая машина»** — она появится у всех участников. Личные машины
   видны только на своём телефоне.

## Как устроена сборка

- Каждый push на GitHub запускает сборку и тесты (вкладка **Actions**).
- Когда в начале [CHANGELOG.md](CHANGELOG.md) появляется новая версия, сборка ставит тег вида `v0.1.0`
  и создаёт релиз с файлом `steamgarage-0.1.0.apk`. Тег, поставленный вручную, тоже создаёт релиз.
- Версия приложения берётся из тега, номер сборки (`versionCode`) растёт с каждым релизом.

## Для разработчика

- Kotlin 2.4, Jetpack Compose (Material 3 со своей темой), Android Gradle Plugin 9.4, Gradle 9.8,
  compileSdk/targetSdk 37, minSdk 26.
- Сборка локально: `./gradlew testDebugUnitTest assembleRelease` (нужны JDK 17 и 21 и Android SDK:
  код компилируется под 17, тесты Robolectric идут на 21).
- Скриншоты экранов: `./gradlew -Pscreenshots testDebugUnitTest`, PNG — в `app/build/outputs/roborazzi/`.
- Структура пакетов — в разделе «Стек и сборка» SPEC.md.
- Лицензии шрифтов и других ресурсов — в [LICENSES-ASSETS.md](LICENSES-ASSETS.md).
